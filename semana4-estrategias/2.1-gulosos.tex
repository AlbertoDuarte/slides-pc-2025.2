\begin{frame}{Algoritmos gulosos}
    \metroset{block=fill}

    \begin{block}{Definição}
        Cormen define um {\bf algoritmo guloso} como um algoritmo que toma decisões ótimas localmentes, com o intuito de obter uma solução global ótima.
    \end{block} \pause

    Dificuldades:
    \begin{itemize} \pause
        \item É necessário entender bem as propriedades do problema. \pause
        \item Pode-se perder muito tempo em uma solução gulosa incorreta. \pause
        \item Em muitos casos, não existe solução gulosa conhecida para o problema.
    \end{itemize} \pause

    Vamos aprender a argumentar a corretude de um algoritmo guloso.

    
\end{frame}
