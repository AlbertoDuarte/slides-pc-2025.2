\begin{frame}{Problemas de otimização}
    \metroset{block=fill}

    \begin{block}{Definição}
        Um problema de otimização é um problema no qual devem ser feitas escolhas para maximizar (ou minimizar) uma função.
    \end{block} \pause

    {\bf Exemplo.} Uma quantidade $n$ de filmes será exibida no cinema hoje. Cada filme tem inicio $s_i$ e fim $f_i$. Qual é a maior quantidade de filmes que uma pessoa pode assistir, considerando que não consegue assistir dois filmes simultaneamente? \pause

    No exemplo, as escolhas são quais filmes assistir, e a função a ser maximizada é a quantidade de filmes assistidos. \pause

    Existem várias técnicas para resolver problemas de otimização.

    \begin{itemize} \pause
        \item Algoritmos gulosos, \pause
        \item Busca completa (e programação dinâmica), \pause
        \item Busca binária, no caso em que a função é monotônica, \pause
        \item Outras técnicas, que não serão discutidas aqui.
    \end{itemize}

    
\end{frame}
